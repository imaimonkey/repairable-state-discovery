# V2 Scientific Contract — Counterfactual State-Level Recoverability

Status: **FROZEN DESIGN**. This document supersedes the V1 full-paper matrix as the scientific contract for the final paper. V1 runs remain valid historical/exploratory evidence and must not be overwritten or silently reused as V2 evidence.

## 1. Scientific object

For an ultimately failed diffusion trajectory with intermediate state `x_t` and gold answer `y`, V2 separates three quantities that V1 partially conflated:

- `o_t = 1[a_t = y]`: observed transient correctness of the provisional answer.
- `q_C(x_t) = P(Y_final = y | x_t, native continuation)`: native recoverability with no explicit repair.
- `q_R(x_t) = P(Y_final = y | R(x_t), phase-faithful continuation)`: recoverability under a specified intervention `R`.
- `Delta_R(x_t) = q_R(x_t) - q_C(x_t)`: intervention lift over native recoverability.

`repairability` is therefore operator-, checkpoint-, branch-budget-, and evaluator-relative. It is not treated as an intrinsic causal property of a hidden reasoning state.

For the title/question "When does diffusion reasoning become irrecoverable?", define the operational last-confirmed-repairable checkpoint

`T_last^R = max{t : q_R(x_t) >= tau_confirm}`

and report the repairability survival curve `P(T_last^R >= t)` in addition to continuous `q_R(t)` curves. Monotonic decay is not assumed.

## 2. Frozen research questions

1. **Existence** — Do ultimately failed DLM trajectories contain intermediate states with counterfactual recovery potential beyond transient answer correctness?
2. **Source** — Is recovery already available under native continuation, or is it created/amplified by an intervention?
3. **Localization** — Can recovery potential be localized from observable pre-intervention state signals without oracle probe outcomes at inference time?
4. **Generality** — How stable is recoverability across task domains, diffusion backbones, repair operators, decoder phases, and random seeds?

Do not add a fifth headline RQ without an explicit design revision.

## 4. Measurement validity gates

A full V2 GPU run is forbidden until all P0 gates pass.

### G1. Snapshot fidelity
`continue(snapshot, same decoder state, deterministic replay seed)` must reproduce native continuation semantics. Snapshot state must include every decoder variable required for replay, not token ids alone.

### G2. Fixed operator across stochastic replicates
A correction-rate estimate must hold operator hyperparameters fixed. Branches may differ only in their declared stochastic seed. V1's paired temperature/remask-fraction mixture is not a V2 probability estimator.

### G3. True branch seeding
Each branch must reseed Python/NumPy/Torch/CUDA before future stochastic decoding. A seed that only shuffles an already-fixed selected set is insufficient.

### G4. Independent localization and confirmation
Use `B_loc` branches to localize candidate checkpoints and disjoint `B_eval` branch seeds to estimate the selected checkpoint. Do not select and report the same finite-sample maximum.

### G5. OOF state-value estimation
Every headline learned-selector score must be generated by a model that did not train on that item's checkpoints. Use grouped cross-fitting by item. All-zero/non-repairable trajectories must not receive artificial positive checkpoint labels.

### G6. Actual compute accounting
Record model forward evaluations/NFE for every continuation and intervention. Main compute controls must use actually decoded fresh samples; analytic extra-sampling approximations are appendix-only.

### G7. Prospective policy accounting
Separate retrospective diagnostic recovery from prospective policy value. Prospective evaluation must count degradation of originally successful trajectories; it may not protect known successes by construction.

### G8. Task evaluator validity
Each task uses its benchmark-appropriate evaluator. MATH symbolic equivalence, exact-answer tasks, and code execution must not share a boxed-string equality shortcut.

### G9. Artifact invalidation
A mismatch in the scientific fingerprint invalidates cached downstream artifacts.

### G10. Tests before scale
Replay, seed independence, fixed-operator, independent-oracle, OOF leakage, evaluator, NFE, prospective-policy, and fingerprint invalidation tests must pass before submission of the full V2 matrix.

Primary backbone: LLaDA-8B-Instruct.

Datasets:
- MATH-500 full test split
- GSM8K full main test split

Run the complete checkpoint/operator/selector/control analysis here.

### Tier B — mechanism/operator controls

On paired Tier-A states compare:

1. exact/native continuation (`C`)
2. matched stochastic continuation without state modification
3. random-position remask matched to the targeted operator's number of modified tokens
4. canonical low-confidence remask
5. CoRe as the main external frozen-backbone revision operator
6. DecoCal only if compute/time remains after all P0 and Tier-A requirements are complete
7. actual compute-matched fresh sampling from the prompt as a compute control, not a repair operator

### Tier C — cross-domain validation

Use a pre-declared non-mathematical structured-reasoning set from BBH and MBPP as an executable code domain. These runs are thin validation, not a full factorial repetition.

- canonical repair
- primary non-oracle selector/value estimator
- oracle diagnostic

Dream-v0-Instruct-7B on MATH-500 and GSM8K.

## 6. Canonical operator semantics

The V2 canonical repair operator must be a single fixed specification. The default contract uses:

- position policy: low-confidence committed positions
- remask fraction: 0.25
- minimum remasked positions: 4
- continuation temperature: matched to the base trajectory setting unless a pre-declared control says otherwise
- branch variation: stochastic seed only

Random-remask controls must modify the same number of eligible positions at the same checkpoint and use the same continuation budget.

Hyperparameter sweeps belong in sensitivity/appendix analyses and must never be averaged together as if they were stochastic replicates of one operator.

## 7. Localization and selection

Pre-declared simple selectors:
- random eligible checkpoint
- earliest eligible checkpoint
- normalized quarter-step
- normalized midpoint
- normalized three-quarter step
- confidence-low
- entropy-high
- mask-ratio based

Do not use a hard-coded absolute step named "middle".

The learned component is a **state-value estimator**, not the contribution itself. Primary targets are continuous `q_R` or `Delta_R`; binary labels are secondary. Scores must be grouped out-of-fold by item. State-local features and multi-trajectory features must be reported separately.

State-local features may include normalized refinement time, within-block phase, mask/commitment ratios, confidence statistics, masked entropy, and candidate-change history. Cross-trajectory answer disagreement is an enhanced multi-trajectory feature and must not be described as a single-state feature.

## 8. Primary metrics

Primary measurement metrics:
- `q_C(x_t)`
- `q_R(x_t)`
- `Delta_R(x_t)`
- repairable-but-never-correct rate
- confirmed repairable failed-trajectory rate
- `T_last^R` and repairability survival
- negative intervention/degradation rate
- actual NFE / forward evaluations

Policy metrics:
- prospective item pass@k
- net gain over base
- coverage/abstention
- oracle gap using independent confirmation estimates
- gain per NFE

Use branch-level simulation for item pass@k whenever possible instead of multiplying marginal trajectory probabilities under an independence assumption.

## 10. Claim boundary

The intended final claim is:

> Final failure is an endpoint observation, not a complete description of a diffusion reasoning trajectory. Ultimately failed trajectories can contain intermediate states with measurable counterfactual recovery potential. This potential can differ from transient answer correctness, varies across refinement, and is partly conditioned on the continuation or intervention used to probe it.

A second sentence about non-oracle localization is permitted only if the grouped-OOF prospective evaluation supports it.

Do not claim a universal intrinsic point of irrecoverability, causal reasoning recovery, predictor superiority, or compute efficiency unless the corresponding V2 controls establish it.
