# Live monitoring entry point

This directory is generated by the read-only monitoring process for the
frozen V2 execution matrix. The monitor runs on the controller host in a
separate worktree and pushes snapshots to
`codex/iclr2027-live-monitor-20260923`.

Start with:

1. `attention_required.md`
2. `current_status.json`
3. `v2_experiment_matrix.csv`
4. `submission_readiness.json`
5. `analysis_handoff.json`

The monitor never changes scientific code/configuration, active jobs, paper
sources, or final aggregate artifacts. Unknown or inaccessible observations
are recorded as `UNOBSERVABLE` or `UNKNOWN_EXPECTED_TOTAL`; they are not
filled with guesses.
